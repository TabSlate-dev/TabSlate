## 1. 设计输入与权威关系

本设计整合本次聊天的内容区高保真设计与 [Dashboard 拖拽与微交互设计](2026-10-23-dashboard-drag-and-motion-design.md)。前者规定布局方向，后者提供拖放业务、输入、动画和资源生命周期约束。

**本文是后续整体改版的设计入口。** 未被本文覆盖的拖放细节沿用原设计；发生冲突时以本文为准。原 [拖拽实施计划](../plans/2026-10-23-dashboard-drag-and-motion.md) 仅供拆解参考，不能直接作为本次整体改版的执行计划。

已由用户明确选择：

1. 默认使用紧凑页头，不保留大时钟模式，也不新增对应开关。
2. 全部书签默认只展开排序后的前 3 个收藏集。
3. 首页广告保留，改为工具栏下方的紧凑广告条，随内容滚动。

设计图是视觉方向参考，示例标题、数量、封面与快捷键标注不是数据或功能契约。未展示的功能不能因此被删除。尤其是原图里的 `⌘K`、全部展开、缺失广告和侧栏项目省略，分别由本文的真实快捷键、前三个展开、广告布局及导航保留规则取代。

## 2. 目标、范围与方案选择

目标用户是经常收集网页、整理书签和浏览器标签页的人。成功标准：进入页面即能看到内容；标题和操作不互相挤压；收藏集层级易扫描；拖动时知道来源、目标和动作；松手后的反馈与实际结果一致。

| 方案 | 取舍 |
|---|---|
| **统一布局、卡片和拖放规则，按模块实施（采用）** | 一次解决内容层级、虚拟列表落点与操作反馈之间的冲突；可沿现有组件与 store 边界交付 |
| 仅修改颜色、间距和阴影 | 成本较低，但保留重复页头、展开式操作区、空白解除分组和虚假成功风险 |
| 自由画布/看板、新排序模型或更换拖放引擎 | 会改变信息架构与数据契约；不属于本次整理效率改版 |

主范围：Dashboard 框架、BookmarksContent、FavoritesContent、BookmarkCard、SearchBox 的布局、TabsRail、现有首页/侧栏广告位，以及原拖拽设计内已挂载的输入与目标。

TabsPanel、GroupDetail、ArchiveContent、TrashContent 接入共同的页头与间距；保留各自专用内容和操作语义。TabsPanel、GroupDetail 同时接入原稿规定的拖放反馈。FavoritesContent 共享视觉、布局与多选改进，不新增拖放来源。归档与回收站不成为拖放目标。

不包含：手动排序、插入线、批量拖放、标签树拖放、跨工作区拖放、外部网页/文件拖入、撤销系统、AI、阅读器、详情侧栏、服务端调整、全站 Dialog 改版。未挂载的 GroupsPanel 不接入、不删除。当前并行进行的标签层级工作不被本设计覆盖。

## 4. 页面框架与滚动结构

桌面结构：`工作区 rail → 导航 sidebar → 中央内容 → 打开的标签页 panel`。取消中央内容与右栏外围的悬浮卡片感，改为相邻平面，用细分隔线区分区域。

中央区域从上到下：

1. **框架工具行**：侧栏开关、工作区/页面路径、紧凑时间、主题、语言及项目链接等现有全局工具。高度约 40px；时间显示到分钟，用本地语言/时区格式化，定时更新只重渲染时钟。
2. **路由页头**：唯一的 h1、数量/状态与本页主操作；标题约 24px。搜索与视图工具位于下一行；有筛选条件时再显示 chips 行。
3. **内容滚动区**：首页紧凑广告行（符合展示条件时）→ 收藏集/卡片或专用路由内容。广告随此区域滚动。
4. **底部反馈层**：批量操作栏、解除分组目标；按第 12 节规则协调。

框架工具行与路由页头是滚动区外的普通 flex 子项，`shrink-0`；滚动区 `min-height:0`、`overflow:auto`。不再通过首个虚拟行模拟固定页头。中央内容只有一个纵向滚动容器，左右侧栏各自滚动。搜索下拉位于页头层，不能被虚拟列表或滚动容器裁剪。

短高度窗口（可用高度小于 600px）时，让路由页头进入同一个非虚拟滚动前缀，仅保留框架工具行固定；虚拟列表使用实测前缀高度作为 scrollMargin，定位与深链都扣除该偏移。这样在缩放或窄窗口下不会让页头占满操作区域。

## 5. 响应式与面板状态

| 区域 | 设计尺寸/行为 |
|---|---|
| 工作区 rail | 保留现有 52px，不改工作区管理或认证入口 |
| 导航 sidebar | 桌面 208px；沿用现有折叠与窄屏 Sheet，不重写导航信息架构 |
| 右侧标签页面板 | 展开 248px、收起 44px；收起显示入口和当前所选窗口的可用 Tab 数量 |
| 内容内边距 | 常规 24px；内容宽度小于 640px 时 16px |
| grid | 最小卡片宽度 240px，间距 12px，最多 4 列 |
| gallery | 最小卡片宽度 280px，间距 16px，最多 4 列 |

列数根据扣除 padding 后的实际内容宽度 W 计算：`max(1, min(4, floor((W + gap) / (minCardWidth + gap))))`。W 小于最小卡宽时使用单列并允许卡片收缩，不产生横向滚动。content 和 favorites 共用同一规则。

右栏默认展开。窗口小于 1200px 时右栏自动呈现 44px 收起状态，小于 768px 时隐藏右栏，框架工具行提供到现有 `/tabs` 页的入口；不新增一个移动端 Tab drawer。回到宽屏后恢复用户在本页的展开选择。窄屏的展开按钮导航到 `/tabs`，不会强行挤压中央内容。

右栏选择保存在 Layout 的本页内存状态中，跨路由保留；刷新恢复默认，不新增本地持久化或服务器偏好。切换 grid/gallery 不自动收起右栏，图二表示用户主动收起后的状态。

面板折叠和列数变化不播放宽度/布局补间。正在拖动时：主动切换布局先取消手势再应用；外部 resize 引起断点变化也取消手势并清理反馈，防止源/目标几何失效。普通 ResizeObserver 回调只重算列数，不通过每一像素变化写业务 store。

## 6. 路由页头与搜索契约

`DashboardPageHeader` 负责展示，不通过 pathname 自行读取业务 store。路由组件提供 title、count、primaryAction、search 与 toolbar 插槽。`DashboardTopbar` 只负责框架级入口，不再给所有路由注入书签筛选器。

| 路由 | 主操作与工具 |
|---|---|
| 全部书签/单收藏集 | 添加书签；紧凑/封面、现有排序、现有类型筛选、标签 chips |
| 收藏 | 添加书签；紧凑/封面、现有排序、标签 chips；不展示当前不生效的类型筛选 |
| 打开的标签页 | 刷新、保存窗口；保留分组和未分组内容，不显示书签视图切换 |
| saved group 详情 | 保留重命名、颜色、打开、保存等已有操作；去掉重复框架标题 |
| 归档/回收站 | 保留各自恢复、删除、清空与选择逻辑，不增加书签排序/拖放能力 |

每个活动页面仅挂载一个 SearchBox。书签集合页传实际 collectionId；全部书签与其他路由不传 collectionId，搜索范围标签明确为“当前工作区书签与标签页”。其他路由的搜索不会声称在搜索回收站、收藏子集或已保存组内项目。

保留原有导航搜索：打开的 tabs → bookmarks → 网页搜索；选择已打开地址切换过去，否则当前页打开；网页回退仍为 CURRENT_TAB。集合过滤仅作用于书签结果，跨窗口 Tabs 仍可出现；`collectionId === ""` 必须按明确集合过滤。保留当前认证、归档结果标记和服务端搜索能力边界，本轮不新增 guest 本地搜索索引，也不把 SearchBox.query 写入 searchQuery 来过滤卡片。

搜索输入改为 36–40px 高的轻边框圆角矩形；移除大胶囊、毛玻璃和重复搜索图标。保持提交和方向键选择能力。保留 `tabslate-focus-search` 监听；仅显示从浏览器 commands 读取到的实际绑定，读取失败不展示快捷键。默认配置为 Cmd/Ctrl+Shift+K，不能照概念图硬编码 Cmd/Ctrl+K。

每行空间不足时搜索占一整行，其余控件下一行；按钮保留可访问名称。主题、语言、GitHub 链接可收进全局更多菜单，不删除入口。已有全局 BookmarkDialog、SettingsDialog、ImportDialog 继续由 WorkspaceRail 挂载。

## 7. 收藏集、筛选和空状态

### 7.1 默认展开与记忆

“前 3 个”指当前工作区活跃收藏集的既有排序：Default 固定第一，其余 position 降序；空收藏集也占一个名额。不改变收藏集排序或新建 position 规则。

工作区在本页首次展示时，按当时有效列表初始化展开映射：前 3 个 true，其余 false。列表为空时推迟初始化；后续新出现的收藏集默认折叠，不重算并覆盖用户选择。显式进入单收藏集不受此限制。未分类分段不占前三个名额，有内容时默认展开。

展开状态按 workspaceId + collectionId 保存在 Dashboard UI 内存状态中，跨路由与本页工作区切换保留，刷新重新初始化；不写入现有 bookmarkView 同步键。隐藏/已退休工作区不可通过这个状态重新暴露。

筛选时，仅展示有匹配项的收藏集并临时展开它们；用户可在本次筛选会话折叠，清除筛选后恢复原来的普通展开状态。筛选会话由标签集合、类型筛选及已有 searchQuery 共同确定；SearchBox 的导航 query 不参与。默认模式展示空收藏集标题与简洁空提示，不为每个空集合常驻大虚线框。

### 7.2 分段结构

集合标题约 40px：展开按钮 + 图标 + 名称 + 淡化数量 + 分隔线。集合复选框独立于展开按钮，避免按钮嵌套和点击同时展开/多选。平时不使用实体底色容器、大阴影或缩放；drag/focus/selected 分别有明确状态。

折叠收藏集的标题本身就是有效目标。拖动悬停不自动展开、不切换收藏集，避免重排列表与焦点跳动。用户若要查看内容，先结束拖动再展开。

### 7.3 空状态与选择

- 首次空工作区：显示“添加书签”与“导入书签”入口，Default 仍可接收拖放；没有有效 Default 时不假装可以保存。
- 空收藏集：显示简短空提示与添加入口；拖动有效来源时才显示目标边框和具体动作。
- 筛选无结果：显示“清除筛选”，一次清除全部标签、类型及已有列表 searchQuery，不误清导航搜索或改变收藏集。
- 内容由同步退休/删除变为不可见：沿用可见性守卫与集合重置；不得保留旧标题形成可写目标。
- 多选继续使用现有 SelectionOrdersProvider：viewOrder 包含折叠组，onScreenOrder 排除折叠组，但包含虚拟化未挂载的逻辑可见行。更改列数不改变数据顺序。
- revealBookmark 与深链仍可明确展开目标收藏集并定位；普通拖放成功不调用它们。

## 8. 卡片与视觉系统

### 8.1 固定层级与操作位置

紧凑卡片：favicon 24px + 最多两行标题；下一行显示 host；底部一行显示标签与操作。基础高度约 132px，内部 padding 12px。短标题也保留两行槽位；没有标签/备注仍保留 footer 高度。紧凑模式不展示 description。完整 URL 仍可在编辑、复制及可聚焦的域名提示中访问；非法/特殊 URL 使用安全的文本回退，不能因格式化 host 导致整卡报错。

封面卡片：顶部 BookmarkCover，比例 1.91:1；下面同一套两行标题、host、最多两行 description 与 footer。文字面板约 160px，短内容保留槽位。封面缺失/失败继续使用 BookmarkCoverPlaceholder，不请求新元数据或添加假截图。按行对齐，不引入 masonry。

操作重新分配，**取代旧稿在标题旁预留 56px 的方案**：

- 标题行右侧仅保留 28px 的“更多”固定入口；拖动手柄在 footer 左侧预留槽位，不挤压标题。
- footer 右侧固定预留两个 28px 操作位，分别为收藏/复制；hover、focus-within、菜单打开时显示，收藏已激活时保留状态图标。
- 备注图标位于 host 行右侧固定槽位；继续打开 BookmarkNotesPopover 与统一编辑对话框。
- 标签区占 footer 剩余空间，最多两个可见 chip，其余显示 +N；复用 TagList，不复制标签筛选/溢出逻辑。超长 chip 截断且保留可访问全名。
- hover/focus 只改变 opacity、背景/边框，不用 max-width 展开、不移动文本、不放大整张卡片。无 hover 的输入环境显示手柄和操作。
- checkbox 继续占据 favicon 或封面左上角的既有位置，悬停/聚焦/选择模式下出现，不移动卡片布局。
- 保留 smartOpen、修饰键选择、Shift 范围选择和右键菜单。拖动完成后的合成 click 不得打开网页。

卡片根节点不使用包裹交互控件的大 button/link。提供独立可聚焦的打开入口、手柄和菜单按钮；鼠标可点击非交互正文打开，但不得造成嵌套按钮/链接。

多选状态不支持拖动：有任何选中项时，书签正文与手柄都不启动拖动；手柄使用不可用状态与说明“请使用批量移动”，批量操作栏保持可用。这样不会出现明明选中 8 项却只移动 1 项的歧义。Tab 拖动仍可用，选择集合不被自动清空。FavoritesContent 等没有拖动包装的复用场景不渲染手柄按钮，只保留相同的 footer 对齐规则。

### 8.2 视觉令牌

作用域限 Dashboard，不全局重定义 primary、Button 或 Dialog。

| 用途 | 浅色建议 | 深色建议 |
|---|---|---|
| 内容底色 | #F7F8FA | #15171B |
| 卡片/面板表面 | #FFFFFF | #1D2026 |
| 主文字 | #20242B | #EEF0F4 |
| 次文字 | #626B78 | #ADB5C2 |
| 细边框 | #E3E6EB | #343A45 |
| 交互强调 | #3F5ED7 | #9CB4FF |

颜色是实施起点，验收需测量正文、辅助文字与焦点/选中态对比度。标签和 Chrome group 颜色沿用现有数据。添加书签主按钮保持中性高对比；选中/聚焦/允许放置使用局部蓝色令牌。

卡片圆角 10px，按钮约 8px。平时无大阴影；浮起拖动预览使用轻阴影。图标控件鼠标目标至少 28px，在 coarse pointer 环境扩大到 44px并允许 footer 增高；浏览器缩放/文字放大时允许行高增长并重新测量，不裁掉内容。

## 9. 广告与右侧标签页面板

首页广告沿用 homepageAds 的来源、tier 和顺序，只在全部书签且没有列表筛选时显示；无广告时不占空槽。它是滚动内容的首行，位于页头下、收藏集前，高约 56–64px，小屏可增高到两行。

横条显示 favicon、标题、简短描述、广告标记与行动入口。多个广告一次展示一个，提供上一条/下一条与序号；不自动轮播、不复制广告数组制造无限滚动。保留所有投放项的手动访问，不混入 sidebarAds、不新增埋点或修改计费逻辑；布局变更不承诺曝光量保持一致。广告目标链接和行为沿用当前契约，不让它看起来是书签或拖放目标。

广告数据在拖动期间变化时，保持当前可见条目和高度稳定到手势结束；无广告→有广告的插入也延迟到结束。正常加载后由虚拟列表重测并保持滚动锚点，不能把广告变化叠加成书签位置动画。

右栏顶部为“打开的标签页”、数量、窗口选择与收起按钮；列表项约 48px，高密度平面列表，显示 favicon、标题和 host，保留当前标签状态。每行拆为独立打开按钮与拖动手柄。整行无默认卡片边框，hover 背景轻微变化，不增加本轮未设计的关闭标签功能。

原 sidebarAds 继续由 TabsAdStrip 展示，迁至右栏底部、提示文字上方的有界区域；保留现有最多 3 条规则。广告区域可滚动且不超过面板可用高度 25%，标签列表可伸缩。右栏收起/隐藏时不占广告空间；不合并两种 tier。

footer 平时提示“拖入收藏集即可保存”，拖动时根据实际 intent 显示“保存书签，保留原标签页”等提示。读取失败、加载中与无可用 Tab 分别呈现，不将 API 失败写成“没有标签页”。关闭/更换浏览器窗口后修正窗口选择，源有效性仍由执行器复查。

## 10. 拖放业务与输入契约

沿用原稿第 4–5 节的领域类型、策略/执行分层、严格去重、配额与权限边界，并补充本设计的选择模式、布局切换和可见目标规则。

| 来源 → 目标 | 操作及来源处理 |
|---|---|
| 活跃书签 → 其他活跃收藏集 | 移动；当前所属集合为 noop |
| Tab / Chrome 标签组 → 活跃收藏集 | 保存为书签；浏览器源保留 |
| Tab → 其他 Chrome 标签组 | 加入目标组；当前组为 noop |
| Tab / Chrome 标签组 → 当前打开的 saved group 详情 | 保存到已有组；浏览器源保留 |
| Chrome 标签组 → 侧栏“已保存标签组”区域 | 创建 saved group；浏览器源保留 |
| 已分组 Tab → 明确解除分组区 | 解除该 Tab 分组，不关闭 Tab |
| 任意来源 → 空白/不可用/不支持目标 | 取消，无写入 |

all/未分类别名继续解析为实际 Default collection；预告使用真实目标名，缺少有效 Default 时拒绝，不能把 all 写入 collectionId。来源、目标及父工作区在执行前均重新校验；Chrome 查询 await 之后、写入之前再校验。跨窗口 Tab 可保存，不能只用当前窗口列表判断是否存活。

领域边界保留 `parseDropTarget`、`resolveDrop`、`readDropSnapshot`、`executeDrop`；DropResult 的 applied/partial/noop/blocked/failed 与 appliedCount/skippedCount 仍代表真实本地结果。applied 不等于 IDB 或服务器同步完成。执行阶段才做重复检测和配额，不在 pointermove 中扫描书签库。partial 汇总保存/跳过数量，QuotaAlert 保持唯一配额提示入口。

鼠标/笔：手柄移动 4px、非交互正文移动 6px 启动。触摸：只允许手柄长按 250ms、容差 5px，正文保留原生滚动。只有手柄设置 touch-action:none。sensor 实例复制 options 后选择约束，activator 不修改共享配置。

菜单、Dialog、链接、编辑区域、checkbox、非手柄按钮不启动拖动。右栏“打开”按钮是明确的非拖动区域；行内剩余非交互正文才可用正文规则。所有手柄为具名 button，连接 setActivatorNodeRef 与键盘 listeners。

键盘沿用原稿：手柄 Space/Enter 启动，Down/Right 前进、Up/Left 后退，不循环；Space/Enter 提交；Esc/Tab 取消并恢复焦点，再次 Tab 才进行普通导航。同逻辑目标去重，优先侧栏行、内容标题、内容 band。只使用已挂载、可见且有效的候选；滚动至目标使用 auto。右栏收起的入口不是放置目标；窄屏隐藏侧栏不进入候选。

程序化取消必须结束 sensor 监听而非仅清空 React state。取消键 preventDefault，避免同时触发多选清空；不 stopPropagation 阻断 sensor 的正常清理。路由/工作区变更、失焦、页面隐藏与卸载按原稿结束手势。已提交操作不能因视觉清理而声称回滚。

## 11. 虚拟列表与整段收藏集高亮

### 11.1 测量与逻辑身份

保留按行虚拟化，不改成整收藏集一次挂载。每个 row 仍有独立 droppable ID；定位 transform 在外层，droppable 测量节点在内层。颜色/边框与动画都不接管虚拟行的定位 transform。

在行模型中维护每个收藏集的首尾 row index，供范围计算；这里只是由现有列表派生的索引，不复制业务数据。标题、卡片行和空行归属于同一个 targetKey。

新增仅供展示的 `surfaceKey` 区分同一目标的多个屏幕表示：例如 `content:<workspaceId>:<collectionId>` 与 `sidebar:<workspaceId>:<collectionId>`。原 droppable ID 继续用于碰撞和锚点，targetKey 用于业务与键盘去重，surfaceKey 用于高亮。surfaceKey 不参与 API 或持久化。

### 11.2 高亮实现

内容区被命中时，使用一个 pointer-events:none 的背景/轮廓层覆盖该收藏集的可见范围，位于卡片后方。范围来自虚拟器的首尾行 offset/size，按实际滚动容器裁剪；不逐帧查询全部 DOM 行、不挂载屏外书签、不改变行高。

收藏集部分滚出视口时只展示可见背景与左右边界；上下边界仅在真实分段起止进入视口时显示，避免把窗口裁剪边缘伪装成集合边界。折叠时范围仅为标题。单收藏集视图覆盖其列表内容，页头、广告和批量栏不包括在内。

悬停于侧栏时只高亮该侧栏行，内容区同名收藏集不同时亮起。悬停于内容区时只突出该内容 surface，不把 header 和每个 band 分别画成多个框。边框视觉采用 2px 局部强调色，极浅底色；不缩放。

完成反馈记录 `completedTargetKey`、`completedSurfaceKey` 和 `completedDropId`。有成功项才在实际 surface 淡出 600ms；内容整段作为一个 surface，替代原稿“只亮实际物理 drop ID”对虚拟行过窄的限制。目标 surface 不在当前视口或已卸载时用文案反馈，不滚动、不切换路由、不为它重新挂载全组；在原时间窗口内重挂载可消费剩余时长，过期不重放。

碰撞仍先按策略筛选，再 pointerWithin，最后受约束的 rectIntersection。广告、工具栏、弹层、右栏打开按钮区和批量操作栏不是可穿透的空隙；指针位于这些明确 UI 区域时不回退命中后方收藏集。解除分组必须指针真实进入，不使用矩形回退。边缘滚动只作用于手势所在可滚动区域，不跨列推动其他面板；滚动后重新计算命中与高亮。

列数、viewMode 或卡片文本尺寸变化后重建并测量行；一般布局切换以首个可见书签 ID 与视口偏移恢复滚动位置，找不到时保留相邻集合锚点。集合筛选/导航沿用自身重置规则。深链 scrollToIndex 需要使用移除旧 hero 行后的新索引，短高度布局还要扣除滚动前缀。

## 12. 动效、反馈和图层

| 状态 | 视觉/时间 |
|---|---|
| hover/focus 操作区 | 120ms opacity、背景/边框；焦点环立即出现 |
| 小型动作按钮按下 | 80ms，scale 0.97；整卡/导航不缩放 |
| 拖动中 | 源项 opacity 0.4 保持占位；预览跟手无 transition/弹簧/惯性 |
| 可接受目标 | 实际 surface 的 2px 轮廓与浅底色；明确“保存到/移动到…” |
| 已接受操作的预览收起 | 160ms opacity→0、scale→0.98 |
| 取消/无效/same-target | 源仍存活时 180ms 返回当前源 rect，否则原地淡出 |
| 真正应用成功 | 实际目标 surface 高亮淡出 600ms |

沿用原稿 CSS 动效令牌和 cubic-bezier(0.2,0,0,1)。颜色改用本设计的 Dashboard 局部交互令牌；跟手不增加缓动。纯展示 DragPreview 统一为 240px 紧凑卡片、最大宽 calc(100vw - 32px)，展示 favicon、标题、host 或组名/数量；不订阅业务 store、不包含操作按钮、不取元数据、不复制 gallery 大封面。

动作预告统一位于预览下方；目标标题可同时显示简短“松开以保存…”但不能改变行尺寸。预览超出视口时视觉偏移保持可读，不能改变真实 pointer collision 坐标。无目标为“松开取消”；same-target 提示无改动，不显示允许高亮。重复判定留在执行阶段，拖动预告不声称已检查重复。

默认 dropAnimation 保持关闭。DropFeedbackLayer 在写入前捕获预览/源/目标的几何与会话信息，独立于源组件卸载。WAAPI 只处理 fixed 反馈节点的 transform/opacity。返回时隐藏原项但保留占位，结束恢复；播放中滚动/resize/节点卸载则终止位移并淡出。WAAPI 不可用时直接清理。

异步执行松手即收起预览并播报处理中，待实际结果再提示。失败不播放成功高亮，不宣称回滚；若浏览器结果无法确认，显示 Alert 并静默刷新。执行阶段被配额/最新状态拦截不重建已消失的预览。动画、timer、Promise 回调全部验证 session ID 与 workspace 身份；pending 执行期间只禁止新的拖动，其他操作可继续，执行器负责重校验。

减少动态效果：CSS 与 matchMedia 订阅都响应运行中切换；关闭缩放、返回位移、脉冲，保留静态边框/背景/焦点与文字结果。保留原定位高亮含义但取消 pulse。广告不自动滚动，页面不使用整列 stagger 入场。

图层顺序：内容/收藏集高亮 → 页头/搜索结果 → 底部操作区 → 拖动预览与结束反馈 → 菜单/Dialog 及系统通知。打开菜单/Dialog 前取消未提交手势，避免拖动层残留在弹窗上方。预览/反馈层 pointer-events:none，不拦截输入。

底部规则：BulkActionBar 常驻挂载，显示时贴合中央视口底部且为最后一行预留空间；隐藏时仍允许自身通知显示。解除分组区常驻注册，仅拖动已分组 Tab 时显示，定位于中央内容右下侧、邻近右栏；如果批量栏同时可见则上移到其上方，窄屏为内容宽度内的单独一行。每个区域都有非重叠命中矩形，不能遮挡最后一行可操作卡片。

浮动结果继续用 Alert，配额复用 QuotaAlert。已有多种通知不覆盖在同一坐标：Dashboard 通知位于中央区域右上，QuotaAlert 保留全局顶部；去重信息与部分成功汇总为一次结果通知。普通成功无须弹窗，只用 surface 高亮和简短状态/读屏反馈。

## 13. 无障碍与本地化

- 一个路由一个 h1；收藏集标题具备真实展开 button、aria-expanded 与独立 checkbox。
- 手柄、复制、收藏、备注、面板开关、广告切换均有本地化名称；隐藏操作在键盘聚焦时显示，不能依靠 Tooltip 才知道用途。
- provider 内一个持久 live region 播报启动、语义目标变化、处理中、完成、失败与取消；同一收藏集内部虚拟行切换不重复播报。沿用原稿对 dnd-kit 重复 announcements 的抑制。
- 取消优先恢复源手柄；源卸载则恢复目标可聚焦控件；目标也不可见时回到当前路由标题（tabIndex=-1）。不偷偷展开/导航追踪落点。
- 触摸仅手柄禁滚动，其余区域可滚动；长标题、中文/英文、200% 缩放、深色和 reduce 都纳入验收。
- 新布局文本使用 `dashboard_` 前缀，拖放文本延续 `dashboardDnd_`；复用已有适用键，维护 en/zh_CN 与 placeholders。右栏现有 Window/Opened Tabs/Ads/No open tabs 等硬编码在本轮涉及组件中完成本地化。

## 16. 验收标准

### 16.1 布局与内容

- 首页无大时钟/独立 Hero；一个标题、一处导航搜索、一套适用工具栏；原全局工具与 Dialog 入口可达。
- Default 第一，其余 position 降序；首次仅前 3 个展开；手动折叠、筛选临时展开、工作区隔离与深链强制展开互不覆盖。
- 两种视图按实际中央宽度排列；右栏收起/展开、窄窗口、200% 缩放不造成横向滚动或文字/操作重叠。
- 卡片两行标题、域名、标签/备注/操作均可访问；hover/focus 不推动标题或改变列宽。
- 首页广告保持独立 tier、紧凑且随内容滚动；无自动轮播；右侧广告不压没 Tab 列表。
- 搜索保留原范围/结果顺序/导航与默认引擎回退；删除 Hero 后快捷键仍能聚焦唯一输入。
- 空库、空集合、筛选无结果、长标签、封面失败、加载/读取失败分别有正确呈现。

### 16.2 拖放与业务

保留原稿第 9 节完整测试矩阵，并增加：前三个折叠规则下的目标、广告/工具栏防穿透、侧栏与内容不同 surface、同集合跨虚拟行不闪烁、部分可见集合、布局变化取消、选择模式禁止书签拖动、批量栏与解除分组区互不遮挡。

每个有效来源/目标组合验证成功、same-target、重复、配额、部分成功、源/目标失效、浏览器 rejection 与迟到结果。空白松手不解除分组；保存不关闭源 Tab；业务未成功不亮成功态。鼠标、触摸手柄、键盘完整流程都必须可取消并恢复焦点。

### 16.3 性能与回归

happy-dom 测试验证行模型、排序/展开、policy/executor、session 清理和焦点；几何/WAAPI 使用明确 fake，不把它当真实渲染性能证明。不写只检查 Tailwind 类名或截图像素相等的测试。
